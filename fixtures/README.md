# Benchmark fixture

`structural-benchmark-v1.3dm` is a redistributable Rhino 8 file generated by
`generate_benchmark_fixture.py` with Python `rhino3dm` 8.17.0.

The model uses millimeters and contains a regular point field with deterministic
object IDs, names, layer assignments, and user strings, plus a reusable point
block placed through instance references. It intentionally stays within the
typed structural subset currently supported by `rhino3dm-rs`; it is for a fair
structural-read comparison, not a claim of full Python API parity.

Regenerate it from the repository root:

```bash
.venv/bin/python fixtures/generate_benchmark_fixture.py
```
